## 三个月总路线

路线按常见数字电路考研知识顺序安排；正式考纲发布后，以目标专业代码为单位做增删。

| 阶段 | 周次 | 核心内容 | 阶段验收 |
|---|---|---|---|
| 第一轮：基础恢复 | 第 1 周 | 数制与编码、逻辑代数、逻辑函数表示、代数化简与卡诺图 | 基础转换与化简题正确率 ≥ 85% |
| 第一轮：组合逻辑 | 第 2–3 周 | 门电路、组合逻辑分析与设计、编码器/译码器、数据选择器、加法器、竞争冒险 | 能独立完成“真值表—表达式—电路图”双向转换 |
| 第一轮：时序逻辑 | 第 4–5 周 | 锁存器与触发器、时序电路分析、同步/异步计数器、寄存器 | 能按固定步骤完成状态方程、状态表与时序图 |
| 第一轮：扩展模块 | 第 6 周 | 脉冲波形、555 定时器、存储器与可编程逻辑、D/A 与 A/D 基础 | 对照正式范围完成章节基础卷 ≥ 80% |
| 第二轮：专题强化 | 第 7–9 周 | 化简、组合设计、计数器设计、时序综合、易错专题与限时章节卷 | 主要专题限时正确率稳定 ≥ 80% |
| 第三轮：真题与冲刺 | 第 10–11 周 | 目标院校题型、真题/高质量模拟题、整卷限时训练 | 完整作答，步骤规范，形成稳定时间分配 |
| 第三轮：回炉与考前 | 第 12 周 | 高频公式、错题 D+1/D+3/D+7 回炉、薄弱章补测、轻量模拟 | 错题二刷正确率 ≥ 90%，可闭卷讲清主干框架 |

## 每日学习规则

1. 例题先独立尝试 2–3 分钟，再看讲解。
2. 进制数必须标明下标；补码题必须先写明位宽。
3. 计算题保留关键步骤，只写最终答案按未掌握处理。
4. 当天练习不查笔记，达到验收线才进入下一课。
5. 错题按 D+1、D+3、D+7 重做；只记录“为什么错”和“以后先检查什么”。
6. 视频学习不超过数字电路当日有效时间的三分之一。
