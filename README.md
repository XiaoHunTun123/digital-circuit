## 使用规则

1. 当天未达标，下一学习日先补救 30 分钟，再进入新内容。
2. 视频/讲解不超过当日有效时间的三分之一。
3. 例题必须先独立尝试；订正后要遮住答案重做。
4. 错题记录具体原因和下次检查动作，并在 D+1、D+3、D+7 回炉。
5. 修订后的每日文件可独立学习：包含概念与公式条件、完整推导、8 道解析例题、通常 12 道具体作业及全部解答。套卷日提供 20 道原创练习；最后两天减量，非必做材料保留查阅。
6. 先做题，再展开折叠解析；对照“验算/边界检查”确认过程。不要把阅读答案当成独立完成。
7. 标题中的“真题”或年份沿用原日历复习位置，文件内新编题目不是官方真题。可用持有的正版真题替换限时段；原创练习用于方法训练，不据此推算真实考试分数。
8. 日期、原文件路径及日历链接保持不变；实际完成日期记在每日打卡处。器件范围和考试时长应以目标专业当年官方考纲为准。
