## 三、具体知识讲义与核心公式

### 1. D 锁存器与边沿触发

#### D 锁存器

有效使能期间 Q 跟随 D，称透明；无效期间保持。D 与反 D 送入 RS 路径避免正常输入产生同时置位复位。

#### 边沿 D 触发器

仅在规定有效边沿采样 D，其他时间保持；符号上三角标志表示边沿，时钟端小圆圈常表示下降沿。

#### 异步端

异步清零、置位不等待时钟边沿，常具有更高优先级。先处理异步端，再讨论边沿采样；同时有效的状态按器件规定。

#### 波形步骤

列出每个有效边沿前 D 的稳定值，写新 Q，再保持到下一次更新；传播延迟题将输出变化后移 tCQ，而非立即变化。

#### 从定义到完整推导

锁存器和触发器使用相同数据序列也会不同。设使能/时钟在 0–10ns 为低、10–20ns 为高、之后为低；D 在 12ns 从 0 变 1，初 Q=0，忽略延迟。

- 高有效 D 锁存器在 10–20ns 透明，因此 12ns 输出跟着变 1，20ns 后保存 1。
- 上升沿 D 触发器只在 10ns 采样，那时 D 仍为 0，所以本次输出保持 0，12ns 的变化要等下一上升沿。

画波形时，先把“透明窗口”或“有效采样时刻”标出来，再判断 D。若另有异步清零有效，两者都优先按清零处理，不等待窗口或边沿。

本专题易错检查：锁存器只在边沿更新；边沿触发器在高电平一直跟随。

### 2. 同步计数器与任意模

#### 位数和状态

模 N 至少需 ceil(log2 N) 位，额外编码必须列为无效状态。二进制模 2ⁿ 可把每个高位翻转条件写为全部低位等于 1。

#### T 与 D 实现

加计数 T0=1，T1=Q0，T2=Q1Q0；D 输入由 D=Q⊕T 得到。非二进制计数器先写完整次态表再化简，不能直接截掉多余波形。

#### 自启动设计

未用状态可规定下一拍回到 0，形成确定恢复机制。如果把它们一律当 X 化简，最后必须重新求实际去向，不能自动声称自启动。

#### 改模器件

同步置数在边沿采样控制，异步清零立即响应；检测 N−1 同步回零与检测 N 异步清零是不同方案。

#### 从定义到完整推导

完整设计同步模 6，三位 D 型，共同上升沿时钟，无效 110、111 都回 000。

| Q2Q1Q0 | D2D1D0 |
|---|---|
| 000 | 001 |
| 001 | 010 |
| 010 | 011 |
| 011 | 100 |
| 100 | 101 |
| 101 | 000 |
| 110 | 000 |
| 111 | 000 |

分别把次态每一位为 1 的现态圈组，得到：

- D2=反Q2·Q1·Q0+Q2·反Q1·反Q0；
- D1=反Q2·反Q1·Q0+反Q2·Q1·反Q0；
- D0=反Q0·反Q1+反Q0·反Q2。

实现时各乘积项由与门产生，同一 D 的乘积项用或门合并，反变量由反相器提供。最后代 110、111 检查三个 D 均为零。这一步给出了自启动证据，不能省略。

本专题易错检查：模 N 与最大状态 N 混淆；无关项化简后不验无效状态。

### 3. 寄存器与序列发生器

#### 先约定位序

本课 Q3Q2Q1Q0 从高到低，右移定义 Q3⁺=串入、Q2⁺=Q3、Q1⁺=Q2、Q0⁺=Q1。别凭箭头文字猜实际连接。

#### 环形与扭环

普通 n 位环形单热初态通常有 n 个状态；扭环反馈末位反相，从全零出发有 2n 个状态。其他初态未必属于所需循环。

#### 加载与移位

并行加载优先级由功能表确定；若加载有效就不执行移位。每次更新使用所有旧位，手工推演时先抄旧状态再写新状态。

#### 反馈序列

给定异或反馈必须逐拍迭代判断周期；全零在纯异或反馈里通常是锁死态。不能只因有 n 位就宣称周期 2ⁿ−1。

#### 从定义到完整推导

推导四位右移带并行加载的输入方程。定义 L 为高有效加载、P3…P0 为并行数据、S 为串入；L=1 优先装载，L=0 执行右移。

- D3=L·P3+反L·S；
- D2=L·P2+反L·Q3；
- D1=L·P1+反L·Q2；
- D0=L·P0+反L·Q1。

每个 D 都是一个二选一：地址 L 决定选新并行位还是旧移位来源。例：旧 1010、S=1、L=0，次态为 1101；若同拍 L=1、P=0011，则次态是 0011，与移位结果无关。

这把选择器与寄存器联系起来，也说明优先级可以直接体现在每个 D 的逻辑式中。

本专题易错检查：新旧位串用；环形与扭环周期混记。

### 4. 序列检测与状态机

#### 状态代表信息

检测 101 时用 S0 未匹配、S1 已见 1、S2 已见 10；状态不是“已经输入第几位”，而是需要保留的有效历史。

#### 重叠

S2 遇 1 检测成功后要回 S1，保留末尾 1 作为下一串开头；不允许重叠才回 S0。这一条直接改变输出序列。

#### Mealy 和 Moore

Mealy 输出取决于状态及当前输入，标在转移边；Moore 仅依赖状态，通常需额外成功状态，输出相位可能后移。

#### 实现

先列状态表再编码，按 D 输入等于次态位化简；未用编码给回零转移。最终用包含重叠的输入串逐拍验证输出。

#### 从定义到完整推导

把 101 重叠 Mealy 检测器真正落实到门级。编码 S0=00、S1=01、S2=10，未用 11 对任意输入回 00 且输出 0。

| Q1Q0 | X=0 的次态/Y | X=1 的次态/Y |
|---|---|---|
| 00 | 00/0 | 01/0 |
| 01 | 10/0 | 01/0 |
| 10 | 00/0 | 01/1 |
| 11 | 00/0 | 00/0 |

所以 D1=反Q1·Q0·反X；D0=X(反Q1+反Q0)；Y=Q1·反Q0·X。

检验输入 10101：状态依次 S1,S2,S1,S2,S1，输出 00101。两个成功位置共享中间那个 1，因此成功后保留 S1 是必要的。再代非法编码 11，D1=D0=0，保证回到 S0。

本专题易错检查：成功后无条件回零；状态定义没有说明匹配前缀。

### 作业 7

**核对：** Mealy 输出含 X；只写 Q1 会让 S2 输入 0 也报警。
