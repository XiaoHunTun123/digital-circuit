## 三、具体知识讲义与核心公式

### 1. 数字系统综合设计

#### 把需求写可测试

写输入、输出、时钟、复位、边界和优先级。例如计数到阈值报警，必须说报警是脉冲还是保持、何时清除、是否允许重新启动。

#### 数据通路

计数器、寄存器、加法器存储并操作数据；比较器报告条件。控制器只发加载、计数使能、清零等控制信号。

#### 控制状态

把等待、运行、完成等模式定义成状态。外部异步按键通常需同步、消抖并转单拍脉冲，避免一次按键被多次计数。

#### 验证序列

至少测复位、正常启动、边界触发、连续启动、运行中复位、非法状态恢复。给出逐拍期望值，不能只说“仿真无误”。

#### 从定义到完整推导

完整规定一个“启动后运行三拍完成”的控制器：复位最高优先，START 只在 IDLE 接受；启动边沿把计数置 0，不算运行拍；DONE 保持到复位。

| 边沿事件 | 状态后 | 计数后 | DONE |
|---|---|---|---|
| 复位 | IDLE | 0 | 0 |
| START | RUN | 0 | 0 |
| 第1运行拍 | RUN | 1 | 0 |
| 第2运行拍 | RUN | 2 | 0 |
| 第3运行拍 | DONE | 3 | 1 |
| DONE中又START | DONE | 3 | 1 |

数据通路负责计数，比较器判断旧计数是否为 2；RUN 且旧值为 2 时，下一个边沿既写计数 3 又进入 DONE。若用次态计数比较，也必须与这张行为表一致。检测旧 3 才完成会晚一拍。

本专题易错检查：未说明报警保持还是脉冲；多位跨时钟数据只加两级寄存器就认为安全。

### 2. 序列检测与状态机

#### 状态代表信息

检测 101 时用 S0 未匹配、S1 已见 1、S2 已见 10；状态不是“已经输入第几位”，而是需要保留的有效历史。

#### 重叠

S2 遇 1 检测成功后要回 S1，保留末尾 1 作为下一串开头；不允许重叠才回 S0。这一条直接改变输出序列。

#### Mealy 和 Moore

Mealy 输出取决于状态及当前输入，标在转移边；Moore 仅依赖状态，通常需额外成功状态，输出相位可能后移。

#### 实现

先列状态表再编码，按 D 输入等于次态位化简；未用编码给回零转移。最终用包含重叠的输入串逐拍验证输出。

#### 从定义到完整推导

把 101 重叠 Mealy 检测器真正落实到门级。编码 S0=00、S1=01、S2=10，未用 11 对任意输入回 00 且输出 0。

| Q1Q0 | X=0 的次态/Y | X=1 的次态/Y |
|---|---|---|
| 00 | 00/0 | 01/0 |
| 01 | 10/0 | 01/0 |
| 10 | 00/0 | 01/1 |
| 11 | 00/0 | 00/0 |

所以 D1=反Q1·Q0·反X；D0=X(反Q1+反Q0)；Y=Q1·反Q0·X。

检验输入 10101：状态依次 S1,S2,S1,S2,S1，输出 00101。两个成功位置共享中间那个 1，因此成功后保留 S1 是必要的。再代非法编码 11，D1=D0=0，保证回到 S0。

本专题易错检查：成功后无条件回零；状态定义没有说明匹配前缀。

### 3. 同步计数器与任意模

#### 位数和状态

模 N 至少需 ceil(log2 N) 位，额外编码必须列为无效状态。二进制模 2ⁿ 可把每个高位翻转条件写为全部低位等于 1。

#### T 与 D 实现

加计数 T0=1，T1=Q0，T2=Q1Q0；D 输入由 D=Q⊕T 得到。非二进制计数器先写完整次态表再化简，不能直接截掉多余波形。

#### 自启动设计

未用状态可规定下一拍回到 0，形成确定恢复机制。如果把它们一律当 X 化简，最后必须重新求实际去向，不能自动声称自启动。

#### 改模器件

同步置数在边沿采样控制，异步清零立即响应；检测 N−1 同步回零与检测 N 异步清零是不同方案。

#### 从定义到完整推导

完整设计同步模 6，三位 D 型，共同上升沿时钟，无效 110、111 都回 000。

| Q2Q1Q0 | D2D1D0 |
|---|---|
| 000 | 001 |
| 001 | 010 |
| 010 | 011 |
| 011 | 100 |
| 100 | 101 |
| 101 | 000 |
| 110 | 000 |
| 111 | 000 |

分别把次态每一位为 1 的现态圈组，得到：

- D2=反Q2·Q1·Q0+Q2·反Q1·反Q0；
- D1=反Q2·反Q1·Q0+反Q2·Q1·反Q0；
- D0=反Q0·反Q1+反Q0·反Q2。

实现时各乘积项由与门产生，同一 D 的乘积项用或门合并，反变量由反相器提供。最后代 110、111 检查三个 D 均为零。这一步给出了自启动证据，不能省略。

本专题易错检查：模 N 与最大状态 N 混淆；无关项化简后不验无效状态。

## 四、典型例题：先尝试，再展开完整解答

### 例 1｜先约定计数边界

设计启动后计满 6 个有效时钟周期即保持 DONE=1 的控制流程，复位清零，DONE 状态忽略 START。

<details>
<summary>例 1：解题步骤、答案与检查</summary>

三态 IDLE、RUN、DONE；IDLE 遇 START 边沿置计数 0 并进入 RUN，此边沿不算运行拍；RUN 每拍加 1，旧计数为 5 时在该边沿进入 DONE；DONE 保持，复位回 IDLE。

**答案：** 启动后第 6 个运行边沿进入 DONE。

**验算或边界检查：** 单独约定启动拍是否计数避免差一；保持报警不是单拍脉冲。

</details>

### 例 2｜最长有效前缀

设计允许重叠的 101 Mealy 检测器，给完整状态表。

<details>
<summary>例 2：解题步骤、答案与检查</summary>

S0 无匹配，S1 已见 1，S2 已见 10；检测成功保留尾部 1。

| 现态 | 输入 | 次态 | 输出 |
| --- | --- | --- | --- |
| S0 | 0 | S0 | 0 |
| S0 | 1 | S1 | 0 |
| S1 | 0 | S2 | 0 |
| S1 | 1 | S1 | 0 |
| S2 | 0 | S0 | 0 |
| S2 | 1 | S1 | 1 |

**答案：** 三状态即可，成功转移 S2 --1/1→S1。

**验算或边界检查：** S1 遇 1 仍留 S1，而非回 S0，因为新的 1 可作开头。

</details>

### 例 3｜先位数后逐态

设计同步模 8 计数，使用最少 D 触发器，无效态下一拍回零。写完整次态表。

<details>
<summary>例 3：解题步骤、答案与检查</summary>

2^2<8≤2^3，需 3 位。有效末态 7 回零，无效态也回零。

| 现态 | D=次态 |
| --- | --- |
| 000 | 001 |
| 001 | 010 |
| 010 | 011 |
| 011 | 100 |
| 100 | 101 |
| 101 | 110 |
| 110 | 111 |
| 111 | 000 |

**答案：** 需 3 个触发器；连接各 D 为表中对应次态位的逻辑函数。

**验算或边界检查：** 全部 2^bits 状态已规定，可以再用卡诺图化简且保留回零要求。

</details>

### 例 4｜同步、消抖、边沿检测分工

机械按键按一次却计数多次，说明输入处理链和两级同步器的边界。

<details>
<summary>例 4：解题步骤、答案与检查</summary>

异步单比特先同步到时钟域，随后用连续稳定计数等方法消抖，再检测 0→1 产生一个周期脉冲。两级同步降低亚稳传播概率，不消除机械抖动。

**答案：** 单比特同步→消抖→单拍事件→计数。

**验算或边界检查：** 两级同步也不能直接保证多位总线一致跨域。

</details>

### 例 5｜边读边保留前缀

101 重叠检测器初 S0，输入 10101，逐拍给 Mealy 输出。

<details>
<summary>例 5：解题步骤、答案与检查</summary>

| 拍 | X | 现态 | 次态 | Y |
| --- | --- | --- | --- | --- |
| 1 | 1 | S0 | S1 | 0 |
| 2 | 0 | S1 | S2 | 0 |
| 3 | 1 | S2 | S1 | 1 |
| 4 | 0 | S1 | S2 | 0 |
| 5 | 1 | S2 | S1 | 1 |

**答案：** 00101

**验算或边界检查：** 输出 1 恰对应截至当前输入的最后三位为 101。

</details>

### 例 6｜低位全 1 才翻转高位

用 T 触发器设计三位同步二进制加计数，给 T 方程和状态循环。

<details>
<summary>例 6：解题步骤、答案与检查</summary>

T0=1；T1=Q0；T2=Q1Q0。代 Q⁺=Q⊕T 得逐拍加 1。

**答案：** 000→001→010→011→100→101→110→111→000。

**验算或边界检查：** 所有触发器共用同一时钟，T 不是后级时钟。

</details>

### 例 7｜优先级直接决定

运行中复位与完成条件同拍有效，规定复位最高优先，下一状态、计数、DONE 是什么？

<details>
<summary>例 7：解题步骤、答案与检查</summary>

先判断复位，清除状态和计数，输出 DONE=0；不再执行完成分支。

**答案：** IDLE，计数 0，DONE=0。

**验算或边界检查：** 实现中同一优先级必须在状态、数据和输出上保持一致。

</details>

### 例 8｜定位唯一输出转移

101 重叠 Mealy 机用 S0=00,S1=01,S2=10，未用 11→00。求输出 Y 表达式。

<details>
<summary>例 8：解题步骤、答案与检查</summary>

只有现态 S2 且 X=1 时输出 1；S2 对应 Q1=1,Q0=0。

**答案：** Y=Q1·反Q0·X。

**验算或边界检查：** Mealy 输出含 X；只写 Q1 会让 S2 输入 0 也报警。

</details>

### 作业 1

**方法：** 先约定计数边界

三态 IDLE、RUN、DONE；IDLE 遇 START 边沿置计数 0 并进入 RUN，此边沿不算运行拍；RUN 每拍加 1，旧计数为 3 时在该边沿进入 DONE；DONE 保持，复位回 IDLE。

**答案：** 启动后第 4 个运行边沿进入 DONE。

**核对：** 单独约定启动拍是否计数避免差一；保持报警不是单拍脉冲。

### 作业 2

**方法：** 先位数后逐态

2^2<6≤2^3，需 3 位。有效末态 5 回零，无效态也回零。

| 现态 | D=次态 |
| --- | --- |
| 000 | 001 |

**核对：** 全部 2^bits 状态已规定，可以再用卡诺图化简且保留回零要求。

### 作业 3

**方法：** 总编码数减有效数

共有 8 码，有效 6 个，差值 2；每个无效码直接指向零。

**答案：** 2 个；若存在无效码最多一拍恢复。

**核对：** 模为 2 的幂时无无效态，不应虚构恢复路径。

### 作业 4

**方法：** 覆盖正常、边界、优先级与重复事件

| 情景 | 期望 |
| --- | --- |
| 复位 | IDLE、计数0、DONE0 |
| 启动后不足阈值 | RUN、DONE0 |
| 最后运行拍 | DONE1并保持 |
| DONE再次START | 忽略，直到复位 |

**答案：** 每种情景都记录逐拍状态和输出。

**核对：** 不能只测一条正常启动序列就宣布全部功能正确。

### 作业 5

**方法：** 检测成功后仍保留后缀

已读到末尾 101；再读 0，末尾 10 可作下一匹配前缀，转 S2；读 1，末尾 1，转 S1。

**答案：** S3:0→S2，1→S1；S3 输出 1，其余输出 0。

**核对：** 不能从成功态一律回初态，否则丢重叠。

**核对：** 代无效 11 得 00，故自启动已验证。
