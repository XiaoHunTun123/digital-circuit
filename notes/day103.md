## 三、具体知识讲义与核心公式

### 1. JK、T 及触发器转换

#### JK 功能

JK=00 保持，01 复位，10 置位，11 翻转；特性方程 Q⁺=J反Q+反KQ。

#### T 功能

T=0 保持、T=1 翻转，Q⁺=T⊕Q。D 型可以用 D=T⊕Q 实现 T 功能；JK 令 J=K=T 也可实现。

#### 激励表

设计时已知 Q 与 Q⁺，反查需要什么输入。JK 的四种状态转移分别允许 0X、1X、X1、X0；X 可在化简时自由取值。

#### 转换验证

把目标次态表达代入源触发器特性方程，对 Q=0、1 均成立才算转换成功。不能只试一次初态。

#### 从定义到完整推导

从 JK 特性方程推导激励表，而不是死记四行：Q⁺=J反Q+反KQ。

当旧 Q=0，式子化为 Q⁺=J，所以 0→0 要 J=0，0→1 要 J=1，而 K 两种都允许。

当旧 Q=1，式子化为 Q⁺=反K，所以 1→0 要 K=1，1→1 要 K=0，而 J 两种都允许。

因此得到 00:0X、01:1X、10:X1、11:X0。例：要做 T 触发器，T=0 时保持，T=1 时翻转，令 J=K=T，代式得 T反Q+反TQ=T⊕Q，完成对全部旧态的验证。

本专题易错检查：特性表与激励表颠倒；翻转时误写成固定置位。

### 2. 同步计数器与任意模

#### 位数和状态

模 N 至少需 ceil(log2 N) 位，额外编码必须列为无效状态。二进制模 2ⁿ 可把每个高位翻转条件写为全部低位等于 1。

#### T 与 D 实现

加计数 T0=1，T1=Q0，T2=Q1Q0；D 输入由 D=Q⊕T 得到。非二进制计数器先写完整次态表再化简，不能直接截掉多余波形。

#### 自启动设计

未用状态可规定下一拍回到 0，形成确定恢复机制。如果把它们一律当 X 化简，最后必须重新求实际去向，不能自动声称自启动。

#### 改模器件

同步置数在边沿采样控制，异步清零立即响应；检测 N−1 同步回零与检测 N 异步清零是不同方案。

#### 从定义到完整推导

完整设计同步模 6，三位 D 型，共同上升沿时钟，无效 110、111 都回 000。

| Q2Q1Q0 | D2D1D0 |
|---|---|
| 000 | 001 |
| 001 | 010 |
| 010 | 011 |
| 011 | 100 |
| 100 | 101 |
| 101 | 000 |
| 110 | 000 |
| 111 | 000 |

分别把次态每一位为 1 的现态圈组，得到：

- D2=反Q2·Q1·Q0+Q2·反Q1·反Q0；
- D1=反Q2·反Q1·Q0+反Q2·Q1·反Q0；
- D0=反Q0·反Q1+反Q0·反Q2。

实现时各乘积项由与门产生，同一 D 的乘积项用或门合并，反变量由反相器提供。最后代 110、111 检查三个 D 均为零。这一步给出了自启动证据，不能省略。

本专题易错检查：模 N 与最大状态 N 混淆；无关项化简后不验无效状态。

### 3. 555 原理与应用

#### 内部阈值

标准 555 基本模型由分压器产生 1/3 VCC 和 2/3 VCC。触发电压低于下阈值使置位，阈值输入高于上阈值使复位，放电管配合电容回落。

#### 单稳态

标准单稳态从零向 VCC 经 R 充电，到 2/3 VCC 结束，t=RC ln3≈1.099RC。推导用 1−exp(−t/RC)=2/3。

#### 无二极管多谐振荡

标准 RA、RB 电路充电经过 RA+RB，放电经过 RB。tH=ln2(RA+RB)C，tL=ln2 RB C；T=ln2(RA+2RB)C。

#### 占空比限制

标准连接 D=(RA+RB)/(RA+2RB)，RA>0 时大于 1/2。若要求小于一半需要改变充放电路径，不能套本式硬解负电阻。

#### 从定义到完整推导

推导标准无二极管 555 多谐的两段时间。电容在 VCC/3 与 2VCC/3 间变化。

充电通过 RA+RB 向 VCC：2VCC/3=VCC+(VCC/3−VCC)e^(−tH/((RA+RB)C))，整理得指数为 1/2，所以 tH=ln2(RA+RB)C。

放电通过 RB 向 0：VCC/3=(2VCC/3)e^(−tL/(RBC))，同样得 tL=ln2 RBC。

取 RA=10kΩ、RB=20kΩ、C=1μF，tH≈20.794ms，tL≈13.863ms，周期≈34.657ms，频率≈28.854Hz，占空比 3/5。这个频率不是 1/tH，必须先把两段相加。

本专题易错检查：单稳态 ln3 与振荡 ln2 混用；忘标标准拓扑。

### 4. 半导体存储器与容量扩展

#### 单位

K 按 1024，容量写字数×字长。2ⁿ 个字需 n 根字地址线，数据位宽由字长给出。总位容量与总字节容量要换算。

#### 位扩展

多片同深度芯片共用地址与片选，不同芯片提供不同数据位。例如两片 1K×4 并行得到 1K×8。

#### 字扩展

低地址接片内地址，高地址译码生成互斥片选；数据总线共享但只有被选片可输出。

#### 地址映射

完整译码给唯一地址块，部分译码可能产生镜像。给定起始地址后用容量减一求结束地址，不能把字数直接当结束偏移。

#### 从定义到完整推导

用四片 1K×8 实现 4K×8，按字节寻址映射 0x000–0xFFF。

| 高地址 A11A10 | 被选片 | 地址范围 |
|---|---|---|
| 00 | 片0 | 0x000–0x3FF |
| 01 | 片1 | 0x400–0x7FF |
| 10 | 片2 | 0x800–0xBFF |
| 11 | 片3 | 0xC00–0xFFF |

低十位 A9…A0 并接全部芯片地址端，高两位经 2-4 译码器产生四路片选。读写控制按规格共用；八根数据线接共享总线，但未选片输出需高阻。

核算：每块 0x400=1024 字节，四块共 4096 字节。若片选只译 A11 不译 A10，就不能得到上述四个独立地址块。

本专题易错检查：地址线数按总比特数算；多片同时驱动总线。

### 5. A/D 转换

#### 四个步骤

采样取时间点，保持维持电压，量化把连续幅值分到区间，编码给二进制。采样率与位数分别控制时间、幅值分辨能力。

#### 量化约定

本课取输入 [0,Vref)，n 位理想截断量化 D=floor(Vin/Δ)，Δ=Vref/2ⁿ。若使用四舍五入量化要另说，二者边界和误差范围不同。

#### 结构

闪速通常需 2ⁿ−1 比较器；逐次逼近逐位比较，理想 n 次决策；双积分对恒定参考积分，速度低但可抑制周期干扰。

#### 采样条件

带限信号理想无混叠需要采样率大于两倍最高频率，等号边界需附加条件，实际留余量并做抗混叠滤波。不能从 n 位推采样速度。

#### 从定义到完整推导

四位 ADC，输入范围 [0,8)V，截断量化 Δ=0.5V，输入 5.7V。Vin/Δ=11.4，向下取整为 D=11，编码 1011。

该代码代表区间 [5.5,6.0)，所以不能仅从代码断言输入恰为 5.5V。若以区间下端作为重构值，误差为 -0.2V；最近量化是另一种规则，不能混用。

以四位逐次逼近说明比较顺序：先试 1000→4V，可保留；再试 1100→6V，过高撤回；试 1010→5V，保留；试 1011→5.5V，保留，最终 1011。这里忽略比较和建立误差，实际转换还包含采样时间。

本专题易错检查：舍入和截断混用；把采样率只设为信号频率。
